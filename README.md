# FlyyFramework (Swift Package)

Swift Package Manager distribution of the Flyy iOS SDK (`FlyyFramework`, binary xcframework, iOS 15+).

## Install

Xcode → File → Add Package Dependencies → `https://github.com/roid-software/flyy-ios-spm` → Up to Next Major Version.

Or in `Package.swift`:

```swift
.package(url: "https://github.com/roid-software/flyy-ios-spm", from: "1.3.157"),
// target dependency:
.product(name: "FlyyFramework", package: "flyy-ios-spm"),
```

## Xcode versions

Each release is built with several Xcode versions. `Package.swift` picks the newest build your Xcode can import, so it works on every supported Xcode without any setting.

`Package.swift` is generated by the SDK release workflow. Don't edit it here.
